# EventEase Blazor App

## 📌 Project Summary / Proje Özeti

**EventEase** is a fictional event management application developed using **Blazor** and enhanced with **GitHub Copilot**. This project was completed in three major phases:

**EventEase**, GitHub Copilot desteğiyle geliştirilen kurgusal bir etkinlik yönetim uygulamasıdır. Proje üç temel aşamada tamamlanmıştır:

---

## ✅ Copilot Usage Summary / Copilot Kullanım Özeti

### 🧱 Activity 1 – Foundation / Temel Bileşenler

- Created the **Event Card** component with `EventName`, `Date`, and `Location` fields.  
- Used Copilot suggestions to implement **two-way data binding** and structured UI design.
- Added navigation routing between **event list**, **details**, and **registration** pages.

> Copilot ile Event Card bileşeni oluşturuldu ve çift yönlü veri bağlama başarıyla uygulandı. Sayfalar arası yönlendirmeler tamamlandı.

---

### 🛠️ Activity 2 – Debugging & Optimization / Hata Ayıklama ve Optimizasyon

- Fixed data binding bugs and added **validation** for form fields.
- Handled invalid route errors using Copilot-generated logic.
- Optimized performance for large event lists.

> Copilot ile form doğrulamaları eklendi, hatalı yönlendirmeler düzeltildi ve büyük veri listeleri için performans iyileştirildi.

---

### 🚀 Activity 3 – Advanced Features / Gelişmiş Özellikler

- Built a **Registration Form** with validation (`Name`, `Email`, `Event`).
- Implemented a **Registration Service** for **state management**.
- Created a **participant list** page to display all registered users.

> Kayıt formu oluşturuldu, uygulama durumu (state) yönetimi eklendi ve katılımcı listesi sayfası başarıyla geliştirildi.
